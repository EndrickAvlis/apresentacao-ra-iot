## 🚀 Como Apresentar
1. Dê **dois cliques** no arquivo [`index.html`](file:///c:/Users/endri/Desktop/apresentacao-ra-iot/index.html).
2. Pressione a tecla **`F`** no teclado para entrar em **Tela Cheia** (*Full Screen*).
3. Use a tecla **`Espaço`** ou a **`Seta Direita`** para avançar os slides como em qualquer apresentação real (PowerPoint / Google Slides).

---

## 🎮 Controles e Atalhos do Teclado

| Tecla | Ação |
| :--- | :--- |
| `Seta Direita` ou `Espaço` ou `Enter` | Próximo Slide |
| `Seta Esquerda` ou `Backspace` | Slide Anterior |
| `F` | Alternar modo **Tela Cheia** (Fullscreen) |
| `M` | Ligar / Desligar Efeitos Sonoros |
| `H` | Efeito Salto no Hiperespaço |
| `0` a `9` | Pular direto para o slide correspondente |
